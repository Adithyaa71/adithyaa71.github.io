01 kratos Rust · control

Make the agent prove it.

A Windows desktop broker for AI agents. It acts only if the weaker of two confidences clears the threshold, and reports done only when the screen actually changed.

11 crates · 289 tests · 0 clippy warnings · named pipe, no TCP

github.com/Adithyaa71/kratos ↗

02 bluee-harness Rust · memory

Derive memory. Never write it twice.

An assistant harness whose memory is a projection of one append-only JSONL log, rebuilt from scratch by a reducer. "Why did it do that?" is answered by reading the log.

MiniLM 384-dim · Kuzu graph · MCP tools · no vector database

github.com/Adithyaa71/bluee-harness ↗

03 snarevec Python · retrieval

One embedding model per index.

A local capture-and-embed daemon. Text, code and images go to separate indexes, and vector width is probed, never typed, ever since a silent 1024-versus-768 corruption bug.

768d · 768d · 512d CLIP · local-first · v2.2 installer

github.com/Adithyaa71/snarevec ↗

04 nyx-nvim Python · tooling

Neovim, drivable by an agent.

Neovim, exposed to an agent over MCP. The bridge is small on purpose: attach, edit exact line ranges, evaluate Lua. LSP and treesitter do the understanding.

pynvim · MCP · LSP · treesitter · MIT
