01

kratos

A Windows desktop broker for AI agents. Rust, 11 crates, 289 tests.

Before it clicks, it scores two things: is this the right kind of control, and is it the right one. It acts on the weaker score.

0.99 and 0.61 → 0.61. The bar is 0.70. Refused.

A clear target clears the bar. Then, and only then, it acts.

min(0.98, 0.94) = 0.94 ≥ 0.70

And it proves it: the screen before and after is compared. No visible change, no done.

02

bluee
harness

An assistant harness whose memory is derived from one log. Rust, MCP.

Every event is appended to one JSONL file. Nothing is ever rewritten. A reducer turns it into vectors and a graph.

Delete everything derived.

Run the reducer again. It all comes back, from the log alone. "Why did it do that?" is answered by reading the log.

github.com/Adithyaa71/bluee-harness ↗

03

snarevec

Local capture and search for everything you read. Python.

Text, code and images live in separate spaces, one embedding model each. Vectors from different models never mix.

A query searches only the space it belongs to, filtered by group and modality.

Vector width is measured, never typed. A model that returns the wrong width is refused at the door: a real 1024-vs-768 bug, fixed for good.

github.com/Adithyaa71/snarevec ↗

04

nyx
nvim

Neovim, drivable by an AI agent over MCP. Python.

The agent reads the buffer first. It never edits a line number it guessed.

People count lines from 1. The editor counts from 0. The bridge converts exactly once: buf[start - 1 : end].

The edit lands, then :w. On disk, where git can see it.
