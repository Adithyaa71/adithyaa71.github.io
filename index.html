repo 1/4 · Rust

kratos

A desktop broker that lets AI agents use real Windows apps, refuses when it isn’t sure, and proves the screen changed.

  • 11 cratesin one Rust workspace
  • 26.5 msbroker cold start, p50 (docs/benchmarks.md)
  • 49 testsin kratos-decide alone, all passing
github.com/Adithyaa71/kratos ↗
kratos000

An agent is about to click Delete all.

It scores kind 0.99 and target 0.61. The gate takes the weaker: 0.61 < 0.70. Refused.

It looks again and finds a target it is sure of.

A clear target: min(0.98, 0.94) = 0.94. It acts.

Then it proves it: before and after frames differ. No change, no done.

repo 2/4 · Rust

bluee-harness

An assistant harness whose memory is derived from one append-only log, so “why did it do that?” is answered by reading it.

  • ~17k linesof Rust, 30 modules
  • 1 logappend-only; vectors and graph are projections
  • 80 testsin Rust
github.com/Adithyaa71/bluee-harness ↗
bluee-harness000

Every event lands in one JSONL file.

A reducer projects it into vectors and a graph.

Delete everything derived.

Run the reducer again. It all comes back, from the log alone.

repo 3/4 · Python

snarevec

Local capture and search for everything you read: pages, PDFs, code, images and audio, in separate vector spaces.

  • 3 indexesone embedding model each
  • 7 backendsfastembed, CLIP, Ollama, Voyage and more
  • 5 targetsQdrant, S3, SFTP, WebDAV, JSONL
github.com/Adithyaa71/snarevec ↗
snarevec000

Text, code and images live in separate spaces.

A query flies into the one space it belongs to.

Nearest neighbours light up, filtered by group.

A model with the wrong vector width is refused. Width is measured, never typed.

repo 4/4 · Python

nyx-nvim

Neovim, drivable by an AI agent over MCP: read the buffer, edit exact line ranges, keep LSP in charge.

  • 1 slicethe only place 1-indexed becomes 0-indexed
  • ~2k linesof Python and Lua
  • 16 configsNeovim plugins: LSP, treesitter, git, search
github.com/Adithyaa71/nyx-nvim ↗
nyx-nvim000

The agent reads the buffer first.

It asks for lines 12–14: 1-indexed, inclusive.

The bridge converts exactly once: buf[12 - 1 : 14].

The edit lands, then :w. On disk, where git can see it.
